# POE 寶石價格 (中英對照)

即時顯示 Path of Exile 寶石市場價格，專為繁體中文玩家設計。

🔗 **[立即使用](https://motorrockqoo.github.io/POE-Gems-Price-Tracker/)**

---

## 功能

-  即時撈取 [poe.ninja](https://poe.ninja) 寶石價格
-  英文名稱對照繁體中文，支援一鍵複製
-  動態聯賽選擇（Mirage、Standard 等）
-  多條件篩選：
  -  技能寶石
    - 類型：一般 / 非變異 / 變異 / 卓越 / 覺醒 / 瓦爾 | 汙染 / 未汙染 | 輔助 / 非輔助
    - 等級：1 / 3 / 4 / 20 / 21
    - 品質：0~19 / 20% / 23%
    - 顏色：力量 / 敏捷 / 智慧
  -  灌注寶石
    - 顏色：技能:力量 / 敏捷 / 智慧 | 灌注: 力量 / 敏捷 / 智慧
-  神聖石 / 混沌石雙價格顯示
-  最近 7 天漲跌趨勢
-  中等信心資料標記，低信心資料可選擇性顯示
-  中英文關鍵字搜尋
-  支援手機板顯示

---

## 資料來源

- 價格資料：[poe.ninja](https://poe.ninja)
- 中英對照表：手工整理，涵蓋 768 個寶石

---

## 技術說明

純靜態網頁（HTML + CSS + JavaScript），無需伺服器。  
由於 poe.ninja 不開放跨來源請求（CORS），透過 Cloudflare Worker 作為代理取得資料。
